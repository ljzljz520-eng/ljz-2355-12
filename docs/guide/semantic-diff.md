# 语义差异

比较文档两个**已发布版本**之间的语义差异：标题、参数表与代码块由比较服务解析；前端自动折叠纯格式变化，参数默认值变更与描述润色分级展示，移动段落沿稳定身份匹配，复制段落另行认定。

- **语言敏感空白**：Python/YAML 等语言缩进有语义，不做统一忽略；JSON/JS 等仅空白重排会折叠为「纯格式」。
- **大章节分块**：章节内受限局部匹配，跨块移动由二次匹配识别；比较可中途取消，迟到块不会混入新比较。
- **复杂度预算**：全文最优匹配受 DP 单元预算约束，超预算退化为快速匹配并提示。
- **分享 / 导出**：分享 URL 只引用有访问权的发布版；导出会冻结当前所见差异（含规则版）。
